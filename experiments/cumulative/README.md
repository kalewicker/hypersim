This isolated Cargo workspace implements the first integrated capacity fixture
for `docs/final_cumulative_complexity_experiment_proposal_20261009.md`.
It borrows the preserved LK core/rules/engine/observer crates without changing
them or either existing workspace. Its own graph codec, law and launcher are
versioned here. No ERE learner or externally selected mutation sequence runs
in the endogenous control.

Run the source-freezing wrapper from the repository root:

```sh
python3 experiments/cumulative/scripts/run_readiness.py output/cumulative_readiness_NEW
```

Only development fixtures run. The authored pathways establish capacity and
causal dependence, not evolved innovations. A separate legal-edit-path fixture
selects admitted native bindings to establish accessibility. An autonomous
control uses graph-resident stochastic editors without utility access. The
contract permits 4,000 native rewrites, 300 seconds of fixture execution,
1,200 seconds of build/test/audit work and 128 MiB of sealed evidence.

Raw stage parcels, wallet, editor and executable gene nodes share each cell's
hypergraph. Gene nodes encode adjacent-stage reactions. The native matcher and
apply path execute reactions and generic editor duplication/property jitter.
All matches are enumerated; exceeding an explicit bound rejects the operation
instead of silently truncating. Semantic gene serials determine scheduler order
and keyed draws, independently of node handles and decoded-rule order.

Each supplied parcel carries 16 energy units. Physical settlement returns
0/4/8/14/16 wallet units by its actual final stage; the remainder dissipates.
Execution costs one unit per reaction. Storage costs one plus gene count per
cycle. Duplication costs two; reproduction pays copy costs and transfers eight
existing wallet units to a child. Invalid duplicated stages are retained as
nonexecutable genes and still incur storage/copy costs. There is no complexity
bonus, learned controller, or reward-driven edit selection.

The shared-population continuation runs with a finite reservoir and physical
sites. Each cell retains its own graph compartment. Birth transfers eight wallet
units from the parent and grants zero new environmental energy. Every living
cell pays storage on every tick, including unfed ticks; insufficient payment
causes death, with the dead cell retained in the archive. Fully enumerated keyed
resource and birth arbitration is independently reconstructed by the auditor.
