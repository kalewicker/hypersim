# TA-1 Gate 0 v1 — authored useful inheritance

Development-only contract, 2026-10-16. Freeze before native exposure. This gate
implements the first milestone of the transferable-adaptation plan; it does not
launch discovery, held-out transfer, training, or a scientific campaign.

## Fixed exposure and physics

Exposed development worlds 17 and 23, two arms each: Useful and Ancestor. Both
start with two Delayed five-instruction founders at homes 0/4, rotation 0, B24
endowment, Faithful descendants, semantic-lottery-v1, four workers and 64 ticks.
Useful supplies g103 source2-to-0 only at native paid founder reservations;
Ancestor supplies identity. Parents remain Delayed. Existing handoff rules,
prices, escrow, schedule generation, codecs and live state are used unchanged.
New versioning applies to the TA panel, its registration and decision. No new
checkpoint codec is needed because this gate adds no native state or dynamics.

One additional Useful world17 recovery control stops at committed tick24 and
resumes in a fresh process. It must match the uninterrupted Useful world17
semantic result. It is not an independent replicate or a main denominator member.
Thus five initial cells, six segments, 320 ticks, 14,720 native advances and 46
published states (four times nine plus ten across the recovery chain). No hidden
held-out worlds, replacement, retargeting, horizon extension or native retry.

## Endpoints fixed before outcomes

Primary reproductive endpoint: number of nonfounder offspring that complete paid
development and perform at least one paid action before tick64. Count each once,
including offspring that later die. All born roots remain in the denominator.

Resource endpoint: full-world harvested energy minus native dissipation
(development, attempts, maintenance, request and copying charges). Compute it
independently from all lifetime accounts and reconcile it to the final native
row. Include founders so that founder-funded copying costs are retained. Endowments
and refunds are internal transfers, not yield; initial reserves and unused final
stock are not harvested energy. Report descendant-only harvest descriptively.

In each of both worlds require Useful minus Ancestor >=1 active completed
offspring and >=8 units of net resource gain (one native successful harvest).
These are engineering effect floors, with no power or statistical claim.

For each Useful founder family, identify every actual paid installation child
with Immediate genotype. Installation into that child is reported separately;
it does NOT count as a faithful transmission of an already useful genotype.
Require a chronological path of three subsequent paid Immediate-to-Immediate
transmissions. Every root on that path, including installation child, must
complete development and have >=1 success (not merely an attempted action).
An edge requires a settled native paid request, child identity, full copying
charge5, request charge1, B24 endowment in the replay, unchanged program bytes,
and no refund. Sibling counts and maximum depth alone cannot meet the condition.
Require both families in each world. Censored paths remain failed exposure.

## Verification, budgets and status

Independently reconstruct every accepted event, checkpoint, ledger, request,
lineage and lifetime with the frozen shared replay. Validate every founder
proposal and descendant faithful copy. Recovery results excluding timing must
equal uninterrupted world17. Assert fixed cell/segment/state denominators,
manifest states, no source drift, binary hash and read-only audit. A resource or
replay failure is incomplete evidence, not a biological zero.

Native panel <=3600s; summed advancement <=2400s; independent audit <=3600s;
panel <=512MiB; segment <=32MiB; payload <=16MiB; checkpoint <=2MiB;
existing 256-node/768-edge and matcher ceilings; advancement <=120s per segment.
Keep interrupted manifests and failure receipts. Registration is emitted before
world execution; exclusive output directories prevent overwriting evidence.

Engineering execution, audit passage and gate0 feasibility are separate flags.
All scientific, transfer, discovery, cumulative, fairness, training and launch
acceptance flags remain false even if Gate0 passes. A failed Gate0 stops this
version. No automatic transition to Gate1. Any new version preserves this result.
