## Measurements and decisions

Use `ere_rule_survival_metrics.py` for separate genotype/installed/root first
spells, exact empirical half-life or censor bounds, actual region-touch intervals
and the additional fixed16-step exposure-period comparison. Report all nine
worlds per condition as the fixed cohort, not63 independent stochastic samples.
Any missing target birth stays missing; any absent interval remains unmeasured.

The mechanism requirement is exact restoration of the post-birth program after
all newly damaging supported lesions when fuel is available, finite exhaustion
when fuel is spent, and no unpaid recovery or changed-body admission. Attribute
each ordinary firing to the actual pre-step table. Report original literal
lifetime-ratio flags even if they disagree with the exposure-period comparison.
More paid repairs can lower the literal all-touch interval without extending a
first lifetime; that cannot silently become a stronger persistence claim.

If repair maintains useful activity but genotype/installed first lifetimes still
fall below the exposure period, the result directly identifies a persistence
gap. The next mechanism would be paid prevention or redundancy/repair timing,
guided by that gap. If the action oracle fails to repair the born program, fix
the mechanism before any further training. If the oracle succeeds but the
learned condition fails at birth, diagnose the frozen transfer on the changed
initialization. If both succeed, characterize the measured survival result and
its narrow scaffolding before considering a larger ecology.

This finite hazard assay addresses birth plus maintenance, but does not by
itself establish general autophagy resistance, repair of missing nodes/ownership,
unbounded novelty, ecological resource replenishment or EI/CE. Those limits
must accompany its eventual findings. Scientific acceptance and training
admission require the new prospective receipts; this planning document grants
neither. A negative lifetime result is an informative completed experiment.
