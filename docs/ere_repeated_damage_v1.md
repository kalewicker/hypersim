# Complete-witness repeated-damage ecology v1

This is a fixed diagnostic, not a training campaign or new gate admission.
The profile remains `E2-witness-complete-v1` (family 10, instruction 11).
No new macro, decoder repair, fuel renewal or optimizer is introduced.

## Precommitted design

Run all 48 cells: seeds 984927043601 through 984927043604, A2 protected
and A3 exposed, RepairSealed fuel 0 / 2 / 8, and late ownership loss absent /
present. Each cell requests exactly 64 advancing steps. Total ceiling 3,072
steps; one invocation, no retries, no replacement seeds, no early statistical
stopping. Each cell has the same pure 4x4 periodic binary crystal and one
dormant complete family. Core: label-0 three-variable path-to-star rewiring;
proposal: label-0 three-variable star-to-path rewiring, priority one. No
activation fuel is supplied. Proposal integrity is checked but proposal firing
is not an endpoint of this experiment.

Before step zero, one native Seal binding seals the family's CORE relation,
paying exactly one from a separate isolated Seal instruction. Setup adds two
endpoint marker properties and one isolated ordinary label-777 clock node
with integer counter zero. Markers narrow hazard targeting; they are not an
original-body oracle used by the decoder or repair. Archive both preamble
inventories, native binding, RNG/step probes and a full-store HGSSv2 roundtrip.

The explicit diagnostic-only initialization seam installs a static exogenous
rule suffix after the endogenous world and encoded operations. This is not a
member of the trainable vocabulary and not passed through `meta_rules_toml`.
The suffix is declared in receipts and counted as seeded-editor events. Normal
rollout APIs and vocabulary preflight remain unchanged. No host callback runs
inside the step loop. The native clock rule increments its counter by one;
four higher-priority, ordered hazard rules at counter 7 / 15 / 23 / 31 rewrite
the targeted ternary CORE payload to label zero and increment the same clock.
They also match an already-erased target: four exposures are distinguished
from the number of newly damaging lesions. The optional ownership hazard at
counter 39 similarly erases the binary E_OWNS relation from family to core.
The engine's ordinary conflict resolution ensures a hazard and clock tick do
not both advance the counter. Hazard and repair share family nodes and cannot
fire together. All rewrites use the production matcher/apply path and the
shared simulation loop; no host-side runtime lesions or reconstruction.

All suffix rules have priority 100 (clock) or 200 (hazards), at most three
variables / one edge, no creation schedules, and arm-consistent visibility.
A2 uses the native meta-node label ceiling for the *same* hazard catalogue;
no protected marker check secretly disables the hazard. A3 exposes meta nodes.
Endogenous world productions constrain nodes to label zero, so this assay
isolates exogenous attacks rather than arbitrary world self-erosion. The clock
does not match them. Repair does not repair the clock or ownership.

Epoch one; pooled work/results allowances 50,000 each; MaxParallel; pairing
allowance 16; one thread; metrics every step; no EI/evaluator/legacy causal
observer; family fuel zero; region ceiling 500; default MetaLimits. Caps,
setup failures and partial runs are retained and disqualify contrasts. Archive
all effective configs, raw completed-step observations, native event bindings,
per-window paid traces/instruction states, selected full graph inventories,
compiled-in harness/contract/source snapshots and the exact test binary.

## Endpoints and fixed expected mechanism

Primary: whole-family exact-original valid-step count, repair payments and
latency per newly damaging lesion, final fuel, ownership integrity, installed
world table and real world-only rule fires (excluding the clock). Report all
cells individually and grouped, not just successful trajectories. Record the
installed table from the pre-step compile boundary: damage can retire the
family only at the next boundary; a paid recovery reinstalls it one boundary
later. This one-step convention must not be misreported as cached admission.

A2 should reject all meta attacks, spend no repair fuel, and retain the exact
family. A3 should admit all four CORE exposures. With adequate fuel, each new
lesion should recover exactly on the following step for one fuel; no-fuel
should stay quarantined after the first lesion; fuel two should pay twice and
then remain damaged. Late ownership erasure should invalidate the family even
with fuel remaining, with no paid reconstruction. These are falsifiable
engineering expectations, not filtering criteria. Zero valid changed-body
admissions is required in every cell. An independent Python audit checks
receipt timelines, ownership/obligation inventories, native graph deltas,
operation/fuel accounting, installed tables and rejection controls. It is not
an independent full CandidateRule or bincode decoder.

## Interpretation boundary

Even a pass demonstrates only controlled exogenous repeat damage of one CORE
relation in one nontrivial world rule, finite initial fuel, this horizon and
detector-only ownership loss. The distinct seeds are reproducibility controls;
MaxParallel/deterministic effects may use no engine RNG and need not create
four independent stochastic replicates. Do not claim general metadata
robustness, witness regeneration, arbitrary simultaneous lesions, coordinated
coherent attacks, self-sustaining metabolism, learning or general ecological
maintenance. Semantic gates and new-profile stateability remain pending; old
gates are not reused. All older evidence directories remain immutable.
