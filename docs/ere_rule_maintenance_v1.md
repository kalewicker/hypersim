`configs/ere_rule_maintenance_v1.json`; the versioned native module is
`hg-sim-core::ere::rule_maintenance`, not a modification of the relational

independent auditor tests, source preservation and checkpoint provenance pass.

proposal's left-hand first pattern. Native Seal transforms its binary payload

remains live. Seal uses a separate instruction with one unit of fuel at step0,

All nine observations, 18 policy draws and 63 schedule slots are saved before

The explicit seventh-arm oracle chooses the correct context literals by
declaration. Wrong or missing learned births remain in the nine-world fixed
denominator. One previously exposed deterministic native seed is used; neither
worlds nor arms are independent stochastic replication.

maximum16 pairings, no host mutation callbacks. Static native birth edits run
