## How to interpret the record

Use a run's own manifest/status, findings, audit receipts and frozen sources
together. Completion, accounting passage, independent replay and scientific
acceptance are different claims. Corrected audits are supplements rather than
replacements for the original failure. Reused checkpoints, continuation windows
and recovery segments do not create new independent replicates. No missing or
unmeasured observation is silently converted to zero.

The catalogue indexes intermediate protocols and failed versions as well as the
headline records above. This index does not replace their exact contracts.
